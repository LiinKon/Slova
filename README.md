# Мои слова

Карточки для слов из «Сохранённых» Google Переводчика. Сами карточки создаются автоматически

Для этого на пк версии (или с андроида, если такой функционал есть) экспортируем эксель табличку с сохранёнными словами, заливаем в приложение. После этого настраиваем карточки и радуемся жизни

Голосовая озвучка может быть отвратительной, смотреть по вкусу, есть возможность отключить.

https://liinkon.github.io/Slova/

Чтобы восстановить данные из резервной копии, нужно:
Открыть бургер -> Настройки
Внизу блока Данные -> Восстановить из копии
