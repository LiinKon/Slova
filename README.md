# Мои слова

Карточки для слов из «Сохранённых» Google Переводчика. Веб-приложение (PWA): ставится на iPhone через Safari → «На экран Домой», работает без интернета, все данные хранятся только на телефоне.

## Публикация на GitHub Pages
1. Зарегистрируйся на github.com (бесплатно).
2. Нажми «+» → New repository, назови, например, `slova`, тип Public, Create.
3. На странице репозитория: «uploading an existing file» → перетащи ВСЁ содержимое этой папки (не саму папку) → Commit changes.
4. Settings → Pages → Source: Deploy from a branch, Branch: main, папка / (root) → Save.
5. Через минуту-две сайт будет по адресу `https://<твой-ник>.github.io/slova/`.

## Установка на iPhone
Открой адрес в Safari → кнопка «Поделиться» → «На экран Домой». Дальше открывай с иконки.

## Обновление
Загрузи новые файлы в репозиторий поверх старых. На телефоне приложение подхватит их при следующем запуске с интернетом (иногда нужно открыть и закрыть его дважды).
